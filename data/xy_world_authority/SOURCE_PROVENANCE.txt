The build preserves every 40x40 MapGR region's first 1,600 four-byte raw
permission cells. The compact runtime database includes only permissions whose
Gen 6 semantic byte is 0x20 or 0x27. Those are the same normal-encounter
semantic codes present in the restored Alpha Sapphire runtime authority.

Independent X/Y cross-correlation performed for this build found that, among
valid zone-switch quadrants that can be linked to game-file encounter tables,
0x20 and 0x27 occur in land-encounter zones and zero times in mapped non-land
encounter zones. See verification.json for counts.

IMPORTANT: this package is authoritative for the supplied Pokémon Y source set.
Pokémon X source hashes have NOT been supplied or compared, so this package does
not claim byte-identical Pokémon X world data. Do not synthesize Pokémon X
version-specific data from Pokémon Y.
