Pokebot3DS-CFW unified 3DS firmware path
=========================================

THIS PACKAGE USES ONE boot.firm FOR BOTH ORIGINAL 3DS AND NEW 3DS USERS.
There is no separate N3DS desktop bot and no second SD-card boot.firm.

Protocol additions retained in this unified candidate:
- UDP/4952 read-only RAM protocol.
- UDP/4952 acknowledged HID/touch controller protocol.
- Read-only framebuffer commands 11-12.
- NEW: command 13 CPAD_PULSE with controller capability bit 0x100.
- New 3DS service-latency changes:
    * bridge worker priority 0x24 -> 0x20
    * non-blocking socket poll
    * 2 ms idle worker yield

HF77 uses CPAD_PULSE for the Route 101 DexNav tutorial Poochyena sneak. The
PC requests only a partial tilt and the firmware owns the hold/release timing.
Each pulse returns the injected Circle Pad state to 0x007FF7FF neutral.
