Test on either console model:
1. Back up the current SD-root boot.firm.
2. Copy 3ds_sd\boot.firm to SD root.
3. Boot the 3DS.
4. Rosalina -> Pokebot3DS Bridge -> Enable Both.
5. Keep standard Rosalina InputRedirection OFF.
6. Run the normal PC bot; do not launch a separate N3DS program.
7. Run Connection Test and verify RAM + acknowledged input.
8. Optional: TEST_FRAMEBUFFER.bat <3DS-IP>.
