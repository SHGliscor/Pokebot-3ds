v0p43EH changes
---------------
1. CMD_READ timeout recovery is read-only and bounded.
   After the existing read retries are exhausted, Wild mode performs up to two recovery rounds.
   Each round revalidates PING + GAME_INFO and requires the same title ID, PID and process name before retrying the RAM read once.
   If the bridge remains unavailable or process identity changes, the hunt still Safety HOLDs.

2. Normal grass Wild post-escape field reacquisition now allows up to 8.0 seconds instead of 4.0 seconds.
   The field authority predicate is unchanged: battle inactive, expected zone, duplicate coordinates match, settled tile center, proven encounter terrain, and the normal confirmation samples.
   No gameplay input is sent during this wait.

- firmware / boot.firm
